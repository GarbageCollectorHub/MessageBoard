# Decisions

- **Database:** Для MessageBoard выделена отдельная Azure SQL Database, чтобы изолировать данные проекта.
  Для работы с БД используем EF Core.

- **Limits:** Ограничения длины полей находятся в CommentLimits в Domain и используются в EF configuration.
  Это позволяет хранить значения в одном месте.

- **Secrets:** Секреты и строка подключения хранятся в User Secrets и читаются через IConfiguration.
  В Git добавляем только шаблон без секретных значений.

- **HomePage:** В публичных URL запрещён `UserInfo`, чтобы не раскрывать учётные данные.
  
- **Comment markup:** Разрешаем только теги `a`, `code`, `i`, `strong`.
  Для ссылок допускаем атрибуты `href` (HTTP/HTTPS) и `title`, остальные теги - без атрибутов.
  Разметку проверяем XML-парсером, который проверяет правильность закрытия и вложенность тегов.
  DTD и загрузка внешних ресурсов отключены из соображений безопасности.

- **Replies:** Ответы связываем с родительским комментарием через `ParentId`.
  Перед сохранением проверяем существование родителя. Каскадное удаление отключено, чтобы не удалять ответы вместе с ним.

- **API errors:** Ошибки валидации возвращаем как ValidationProblemDetails, остальные ошибки - как ProblemDetails.
  Для внутренних ошибок скрываем технические детали, оставляя их в логах. В ответы добавляем traceId.

- **Email:** Адрес сохраняем в БД, но не возвращаем в публичных ответах API.
