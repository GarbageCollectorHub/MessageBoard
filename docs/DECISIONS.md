# Decisions

- **Database:** Для MessageBoard выделена отдельная Azure SQL Database, чтобы изолировать данные проекта.
  Для работы с БД используем EF Core.

- **Limits:** Ограничения длины полей находятся в CommentLimits в Domain и используются в EF configuration.
  Это позволяет хранить значения в одном месте.

- **Secrets:** Секреты и строка подключения хранятся в User Secrets и читаются через IConfiguration.
  В Git добавляем только шаблон без секретных значений.

- **HomePage:** В публичных URL запрещён `UserInfo`, чтобы не раскрывать учётные данные.

- **Comment markup:** XML-парсер проверяет закрытие и вложенность тегов, затем проверяем допустимость тегов,
  атрибутов и URL. Некорректную разметку отклоняем. DTD и загрузка внешних XML-ресурсов запрещены.
